## 티어 1 예상 (추정, 미확정)

가정: run당 300k 스텝, 초당 약 2700 스텝 → run당 약 2분.
50 run → 순차 약 100분, 3개 병렬이면 약 35~60분(병렬 시 속도 저하는 측정하지 않았다).
하룻밤(8시간) 예산에는 충분한 여유가 있을 것으로 보인다. 단, 다음은 반영되지 않았다:

- 직접 구현 PPO의 속도(SB3와 다를 수 있다)
- 여러 네트워크(K=4, 32)에서 학습할 때 필요한 스텝 수 — 단일 네트워크보다 많이 든다
- 비용 wrapper·관측 누적 wrapper의 오버헤드
- 평가(학습 풀 + 테스트 A/B 60개 네트워크) 시간

Phase 1에서 직접 구현 PPO로 K=4를 한 번 돌린 뒤 이 문서를 갱신해 티어별 스텝 수를 확정한다.
